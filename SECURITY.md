# Security

Kive takes the security of this repository and the Kive platform seriously.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, email **support@kive.ai** with the subject line `SECURITY` and include:

- A description of the issue and its impact
- Steps to reproduce
- Any relevant URLs, request/response samples, or screenshots

We will acknowledge your report and keep you informed of the remediation progress.

## Scope

This repository contains agent skills, plugin manifests, and documentation. It does not contain the Kive MCP server or API implementations. Reports about the hosted services (`https://mcp.kive.ai`, `https://kive.ai`) are welcome through the same channel.
