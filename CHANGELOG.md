# Changelog

All notable changes to the Kive Claude plugin are documented here.

## 0.2.0 - 2026-11-11

- Build campaigns on looks and ads: the `kive-build-campaign` skill now lets you pick the campaign's look with `find_ideas` and remixes it with your product, matching the Kive MCP server. It no longer searches studios or video presets unless you ask for them.
- Add the listing details Anthropic's plugin directory reads: icon, display name, and documentation, support, privacy policy and terms links.
- Add a README to the plugin folder.

## 0.1.1 - 2026-07-20

- Link completed campaign assets directly to their Kive generation pages.

## 0.1.0 - 2026-07-17

- Configure the hosted Kive MCP server with OAuth authentication.
- Add the `kive-build-campaign` skill for planning and producing coordinated product campaigns.
